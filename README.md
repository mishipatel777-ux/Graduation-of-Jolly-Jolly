# 🎓 Graduation of Jolly Jolly 🎓

A cute, interactive graduation website celebrating the Class of 2026! 🎉

## ✨ Features

- **Interactive Profile Cards** - Click on any friend's profile to see more!
- **Photo Gallery** - Swipe through multiple photos of each graduate
- **Cute Pastel Design** - Beautiful gradient background with soft colors
- **Smooth Animations** - Bouncing titles, card scaling, and confetti effects
- **Mobile Responsive** - Works great on phones, tablets, and desktops
- **Keyboard Navigation** - Use arrow keys to navigate photos, ESC to close

## 🎨 Design Elements

- Pastel pink, purple, and blue color scheme
- Smooth hover animations on profile cards
- Animated gradient background
- Confetti animation on page load
- Beautiful modal with photo gallery

## 🚀 How to Use

1. Click on any friend's profile card to open their detailed profile
2. Use the arrow buttons or keyboard arrows to scroll through their photos
3. Read their superlative, bio, and favorite quote
4. Click the X or press ESC to close

## 📝 Customization

To add your friends' information:

1. Open `script.js`
2. Find the `profiles` array
3. Edit the existing profiles with:
   - `name` - Friend's name
   - `superlative` - Their school superlative
   - `bio` - A fun bio about them
   - `quote` - Their favorite quote
   - `photos` - Array of 3 photo URLs (replace with real photos)

### Example:
```javascript
{
    id: 1,
    name: "Your Friend's Name",
    superlative: "Most Likely to...",
    bio: "Description here",
    quote: "Favorite quote here",
    photos: [
        "photo-url-1",
        "photo-url-2",
        "photo-url-3"
    ]
}
```

## 🖼️ Adding Photos

- You can use photo URLs from services like Unsplash, Pexels, or your own uploaded images
- For best results, use square or slightly rectangular images
- Each friend gets 3 photos in their gallery
